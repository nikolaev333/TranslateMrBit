# Branding rules — TranslateMrBit

## Canonical name

- **Product:** TranslateMrBit
- **Tagline:** AI Transcription Platform
- **Repository:** `nikolaev333/TranslateMrBit`

## Do not

- Rename the product to MrBit Call AI, Nikolaev Speech, Whisper AI, or any other brand.
- Claim ownership of the OpenAI Whisper model.
- Change Coolify service names, Docker Compose service names, volumes, or production env vars solely for cosmetic rebranding.

## UI

Primary brand mark in the header/login:

```
TranslateMrBit
Private AI Transcription Platform
```

## Branching

Commercial-edition work lands on `feature/commercial-edition` first.
Do not auto-deploy branding or commercial features to production without an explicit request.
